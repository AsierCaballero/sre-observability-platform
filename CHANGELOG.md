# Changelog

## [1.0.0] - 2025-12-18

### Added
- Prometheus with alerting and blackbox monitoring
- Grafana with auto-provisioned dashboards
- AlertManager for alert routing
- Loki + Promtail for log aggregation
- Jaeger for distributed tracing
- Node Exporter and Blackbox Exporter
- Health check, backup, and restore scripts
- Grafana dashboards (infrastructure, SLO, logs)
- Sample Flask app with Prometheus metrics
- Kubernetes manifests for Prometheus and Grafana
- Terraform modules for AWS VPC and EKS
- GitHub Actions CI pipeline
- Documentation
